# Relay / 驿站需求与验收

**版本**：v2.0
**状态**：当前产品基线
**最近整理**：2026-10-11

本文件定义已确认的产品目标、业务规则和验收；实现路径见 [DESIGN](DESIGN.md)，长期事实与验证命令见 [AI_CONTEXT](AI_CONTEXT.md)。整理不改变既有需求，未决产品边界保留为 `NEEDS_CONFIRMATION`。

## 1. 产品目标

Relay 是一款面向 Apple Silicon、macOS 27 的菜单栏应用，用于集中查看多个 AI 服务商、多个账户的余额、消费、请求量和 Token 用量。它提供本地优先的观测、历史和整理能力，不负责充值、扣费、模型代理或服务端托管。

目标用户是同时使用多个 AI API 供应商或中转站的个人开发者，以及需要查看同一供应商多个账户状态的用户。

## 2. 产品原则

1. **本地优先**：网络或同步不可用时，仍可读取本地数据和最近成功快照。
2. **账户隔离**：单账户失败、限流或凭据失效不能破坏其他账户。
3. **未知不等于零**：缺失、未支持、过期和真实零值必须区分。
4. **秘密只留本机**：凭据不进入同步、导出、备份、日志、诊断或项目文件。
5. **可解释**：汇总、预算、历史覆盖和模型分析必须说明数据不完整、币种不一致或来源不可用的原因。
6. **界面与视觉体系**：沿用当前菜单栏、Popover、设置分页和辅助窗口的信息结构。按已确认的 HyperOS × iOS 玻璃拟态规范统一原生材质、深浅模式、胶囊按钮、圆形图标按钮、搜索与表单输入、卡片和悬浮操作区；尺寸与信息密度参考替换前的 macOS UI，不沿用移动端触控尺寸；保留业务口径、窗口导航与中性初始焦点。

## 3. 平台与范围

- 平台：macOS 27、Apple Silicon。
- UI：SwiftUI，必要时使用 AppKit；菜单栏常驻，默认不显示 Dock 图标。
- 网络：直接访问供应商 HTTPS API；Relay 不提供远程后端。
- 同步：iCloud Drive 普通文件，仅同步非秘密数据；不使用 CloudKit Container。逻辑目录为 `iCloud Drive/Documents/Relay`（中文“文稿/Relay”），通过系统选择器确认，不硬编码本地化物理路径。
- 当前供应商：Pipio、DeepSeek、workbuddy2api。自定义 OpenAI 兼容类型保留扩展入口，但没有通用账单能力承诺。

## 4. 功能需求

### 4.1 账户管理

- 添加、编辑、启用、停用、隐藏、删除账户。
- 账户字段包括显示名、供应商、站点地址、供应商身份、低余额阈值、账户级汇率覆盖、月预算、分组、置顶和排序信息。
- 预算、分组和置顶在添加/编辑账户表单中与账户信息一次保存；取消或保存失败不产生部分修改。分组去除首尾空白、留空取消分组，最多 40 个字符；预算留空关闭。没有可靠月消费的 workbuddy2api 不提供预算输入，仍可分组/置顶。
- 保存前执行必要的站点和账户验证；凭据替换失败时恢复旧凭据。
- 删除账户前二次确认；清理本机账户、快照和历史，记录传播删除所需的同步 tombstone，再清理本机凭据。凭据已不存在不阻断删除。
- 隐藏账户继续后台刷新，排除首页、总览和通知；停用账户停止采集，保留旧数据。网关按父账户管理，子账户投影继承父账户状态。
- 必填字段缺失时测活和保存都明确列出缺填项；保存失败留在表单并保留输入。

### 4.2 供应商数据

- Pipio：读取站点状态、账户余额/累计数据和看板消费；按能力展示模型、Token、缓存和历史。
- DeepSeek：余额使用官方余额接口；平台历史用量仅使用用户手动提供的可选 `userToken`。
- workbuddy2api：读取网关和子账户状态、积分和可选统计；积分单独展示，不与货币余额合计；累计统计只能解释为观测增量，不能可靠拆回离线各日；子账户启停入口目前保留为 `NEEDS_CONFIRMATION`。
- 所有供应商能力由适配器声明。不可用或未支持的指标显示未知、隐藏或给出原因，不填充零值。

### 4.3 刷新、健康和详情

- 自动刷新默认 5 分钟，按分钟配置，最少 1 分钟；支持 1/5/15/30 等输入。
- 支持手动刷新、账户级刷新、取消、同账户请求合并和同源串行。
- 对 429 解析 `Retry-After` 秒数或 HTTP 日期；对网络和 5xx 退避；401/403 不高频重试。
- 刷新失败保留最近成功快照，显示过期和错误分类；运行期展示最近成功时间、连续失败和退避状态。
- 账户详情显示余额、今日/月消费、请求量、Token、模型统计、缓存能力、固定近 7 日趋势和数据新鲜度；今日或历史不完整时解释缺失原因。
- 在账户管理的编辑账户表单中提供供应商允许的 7/30 日历史补齐，有进度和取消；详情页不提供历史范围选择或回填按钮。今天由正常刷新维护，历史批量提交不得落半批。

### 4.4 汇总、预算和账户整理

- 仅在金额、币种和数据新鲜度满足条件时跨账户汇总；混合币种或换算失效时明确提示。
- 账户级月预算必须为正数并绑定原币种；预算通知在当前月消费可核实、币种一致且数据新鲜时，按账户/月/预算值对 80% 和 100% 去重。
- 首页支持搜索、分组筛选和置顶优先排序；搜索匹配账号名、供应商、站点和分组；筛选不改变总体汇总口径。
- 支持日模型的供应商：模型分析默认显示当天明细，用户点击趋势日期后切换为该日；以单行五列展示模型名、总 Token、缓存占比、百万 Token 平均费用、当日消费。保留消费/Token/名称排序、Top 5 和悬停消费占比；没有该日模型明细时提示未知，不使用今天或月度数据代替。缺金额、缺 Token 和混币种时不伪造结果。部分覆盖不能宣称为完整请求占比，单位成本只针对可确认的行。
- workbuddy2api 模型分析显示网关全部模型的进程累计统计，明确标记“进程累计”，点击趋势日期不切换；五列为模型名、总 Token、缓存占比、积分/百万、累计积分，积分不带货币符号。子账户详情也明确网关范围；未获取统计与已知空列表分别提示，不把累计模型写成日模型。
- 固定近 7 日图表支持点选、键盘与辅助文本，标签密度受控；缺失日期不得补成真实零。

### 4.5 数据同步、导入导出和本机备份

- iCloud 同步文件只包含账户元数据、设置、日/模型聚合和删除 tombstone；本机凭据和目录授权不得同步，同步开关不跨设备启用。载荷中的同步开关由安全投影置为关闭。
- 同步冲突保留候选文件并提示；同步失败不阻断本地读写。
- CSV 按账户和日期范围导出日消费，保留原币种和未知状态，并防止公式注入。
- 配置 JSON 只导入/导出非秘密账户配置和设置；导入先预览，再明确确认；非法字段、敏感字段、超大文件和不支持版本必须拒绝。
- 本机备份在应用运行期间每日自动一次，也可手动或在导入/恢复前创建；正常创建保留最近 5 份，可列出、预览和明确恢复；恢复前保护当前数据，预览过期时拒绝应用。
- 本机备份目录可选择、恢复默认并显示当前路径。目录授权只保存在本机 bookmark；所选父目录下使用 `RelayBackups` 子目录。
- 更换目录先复制并逐文件校验，再更新目录设置并删除已校验的旧原件。复制/校验失败保留旧原件和旧配置；清理失败保留两处有效副本并提示未清理数量；同名不同内容不得覆盖；无关文件不得删除。
- 备份列表和恢复预览日期使用八位 `yyyyMMdd`，时间以 `HH:mm:ss` 作为次要信息。

### 4.6 恢复、诊断与消费整理

- 损坏库提供独立备份恢复入口，不依赖现库可解码；先预览、复核原件与备份、保留损坏原件，再明确恢复。不可读文件或未知版本不得覆盖；恢复后重新录入凭据并关闭同步。
- 新增账户配置、首快照和日历史一次提交；可选历史读取失败不阻止保存已验证账户，取消不写入。失败补偿新凭据，补偿失败可见，不宣称跨文件原子事务。
- 供应商重定向限同 scheme/host/规范端口；跨来源、降级、URL 用户信息或方法改变拒绝，不转发认证。既有 loopback 产品边界仍待确认。
- 备份搬移在本机持久化清单及阶段，重启后支持重新授权和显式重试；核验原件及副本后才清理，内容改变时保留文件，未处理完不裁剪恢复点。
- 通知设置显示系统授权状态，提供主动测试和提交失败反馈；测试不影响真实阈值去重，系统接受请求不等于用户已看到通知。
- 点击首页原有“今日总消耗”卡片打开消费总览，提供当日与月度切换，不增加独立醒目入口；当日按供应商日历统计已记录消费。月度/分组总览展示本月及上月已记录消费、覆盖范围，币种分别显示；积分、隐藏、停用账户不参与。已结束自然日的完整同口径同长度同期数据且上期非零时才显示环比，不推算完整账单。
- 脱敏诊断先预览再主动保存，不自动上传；白名单仅含版本、分类、数量、容量、耗时及布尔状态，不含账号名、ID、地址、路径、原始错误/响应或秘密。
- 备份摘要显示有效份数、容量和最近成功，支持打开目录；配置导入显示字段差异、历史清除和需重填凭据，预览过期继续拒绝。
- 账户管理支持多选分组、隐藏、启停，父账户一次提交，失败不落半批，停用取消在途刷新；删除仍单独确认。

### 4.7 设置、导航和系统集成

- 「数据」页中，数据刷新、历史数据、月预算通知为同级区块。
- 「同步」页按 iCloud、备份、配置迁移和消费记录导出分组；备份列表与 CSV 筛选默认折叠，异常与待处理搬移状态始终可见。
- 备份目录与「打开目录」按钮同行，长路径单行截断，悬停显示完整路径、移开后隐藏；CSV 导出的开始与结束日期同行，不放大设置窗口。
- 设置使用统一的紧凑分组、说明、开关和输入样式；胶囊操作按钮统一靠右，不放大窗口或沿用移动端尺寸。固定菜单栏宽度下不再显示 Hidden Bar 说明。
- 系统通知授权状态/测试、登录项、iCloud 和备份目录选择/重新授权统一放在「快捷键」页；常规/数据只保留各自通知业务开关，常规、数据和同步页不再提供权限跳转入口。
- 「账管」提供账号上移/下移，立即原子保存已有排序字段；包含隐藏、停用和网关父账户，首尾方向禁用。首页继续置顶优先、按服务商分组，子账户跟随网关；不改变其他账号配置或历史。
- 首页“已连接账号”标题右侧提供搜索入口。
- 设置、添加账户、编辑账户和详情显式关闭返回首页；点击应用外部隐藏只保留页面状态。
- 菜单栏使用系统单色闪电和可选今日消费数字，不显示余额/币种/“今日”前缀；固定宽度 70pt。未知金额时只保留入口。
- 全局快捷键支持“显示/隐藏面板”和“刷新全部账户”，可分别留空，不增加“打开设置”动作。支持开机启动和菜单栏今日消费显示；系统注册失败时显示真实错误。
- 原生窗口关闭、取消、完成和保存成功均遵循返回首页；保存失败不清空输入。局部 sheet 返回父页面，退出 Relay 仍退出程序。
- 外观支持跟随系统/浅色/深色；使用共享原生材质和语义颜色，不把参考壁纸颜色固化成背景。
- 打开首页、表单、详情、设置分页与内部 sheet 时，搜索框、文本框与趋势图不得自动获得焦点或选中；点击、Tab 键或辅助操作后才进入选择/编辑状态。

## 5. 数据与安全要求

- 本机业务 JSON、同步 JSON、导出、备份和诊断均不得包含系统令牌、API Key、Pipio 数值用户 ID、DeepSeek `userToken`、Cookie、Authorization 或完整供应商响应。
- 凭据文件目录权限 0700、文件权限 0600；不使用 Keychain 是已确认的安全降级，不能描述为硬件保护。
- 原已确认要求为 HTTPS；workbuddy2api 当前实现允许本机 loopback HTTP 的例外需另行确认，不能据代码改变安全需求。跨 origin 重定向不得继续携带认证头。
- 时间持久化使用 UTC；“今日”和预算月份按业务日历计算；Pipio/网关使用本机日历，DeepSeek 平台历史、今日和预算月份使用 UTC+8 公历。金额使用 Decimal。
- 导入、恢复、刷新和同步写入必须具备原子失败语义，不能静默覆盖用户数据。备份跨目录搬移采用多步保护，不承诺跨目录单次原子事务。
- 首屏立即展示本地缓存，不等待网络；网络和可后台执行的文件准备不阻塞页面操作。
- 接口新增/缺失字段按能力降级；可选统计失败不能丢弃可确认余额，统计口径变化需单独对账，不能用硬编码差值兜底。

## 6. 汇率、保留和发布规则

- Pipio `quota_per_unit` 只从该账户站点读取；不能手动输入或用外汇值兜底。
- 额度/汇率刷新默认每 7 天，可选每天、每周、每月、仅手动；失败保留上次成功值并标记过期。
- USD→CNY 优先使用有效账户手动值，否则使用未过期站点值；手动值必须为正，留空恢复自动，仅修改汇率不要求联网或重填凭据。
- 低余额默认阈值 20，可按账户调整；全局通知需开启并获得系统授权，按账户/自然日去重。
- 历史只保存聚合数据，默认 1 年，可选一月、半年、一年、永久；不长期存原始请求日志。
- GitHub Releases、ad-hoc 签名和手动安装为已确认路线，不使用 Developer ID 或公证，不上架 App Store。
- 应用内更新绑定仓库、Release tag、版本和准确资产名；校验 SHA-256、可用文件长度、路径及重定向，失败清理暂存文件。缺少可信校验值则拒绝应用内下载。
- 同源未签名 checksum 不能认证发布者身份；下载完成后由用户手动安装，应用不自动替换自身。
- DMG 文件本身使用 Relay 正式图标，图标随文件内容分发，下载后不依赖本机 Finder 属性；图标嵌入和验证完成后再生成最终校验值。

## 7. 验收标准

保留既有 AC-001～AC-007 编号；验收项定义预期行为，不能仅依据源码存在标为通过。

| 编号 | 场景与预期 |
|---|---|
| AC-001 | 有效 Pipio 站点、管理令牌和用户 ID 经验证保存后，创建账户、私有凭据和首个快照。 |
| AC-002 | 缺少数值用户 ID 时阻止账户请求，明确提示 `Pipio-User` 必填。 |
| AC-003 | 多账户中一个超时/认证失败时，其他账户继续刷新，失败账户保留旧数据和错误状态。 |
| AC-004 | 未返回缓存能力时隐藏或显示暂不支持，不显示伪造 `0%`。 |
| AC-005 | 添加、刷新、同步、导出、备份和诊断时，秘密只进入本机凭据文件及必要的输入/请求内存。 |
| AC-006 | 今日数据缺失或仅覆盖部分账户时，不显示不完整的今日总消费；对应账户不伪造今日金额。 |
| AC-007 | iCloud 普通文件不含凭据；目录不可用不阻断本机，其他设备需重新录入凭据。 |
| AC-008 | 保存或替换凭据失败保留原配置；删除二次确认且保留传播所需 tombstone。 |
| AC-009 | 退避释放执行名额且同原点冷却不被绕过；取消/编辑/删除后的旧结果不能提交。 |
| AC-010 | 存储打不开时显示持续故障、禁止写入空库；重读成功后恢复，无损坏文件自动覆盖。 |
| AC-011 | 手动汇率按账户保存且即时重算；无可靠换算参数不显示跨币种伪造合计。 |
| AC-012 | 详情走势固定近 7 日，无历史范围选择；7/30 日回填位于编辑账户，取消/失败无半批，今天不被回填覆盖。 |
| AC-013 | 预算通知仅基于新鲜同月同币数据；阈值按账户/月/预算去重，首次超过 100% 不重复发 80%。 |
| AC-014 | 搜索/分组/置顶只影响列表投影；表单偏好与账户一起保存，取消不保存。 |
| AC-015 | 支持日模型的供应商默认当天，点选趋势日期后显示该日；每模型单行五列，历史明细缺失不代用当天/月度数据。workbuddy2api 明确展示网关进程累计、使用积分单位且不随趋势日期切换；父/子账户说明同一网关范围，统计不可用与空列表区分。免费/未知行保留，跨币种不比原始金额，缺值不伪造占比或单价。 |
